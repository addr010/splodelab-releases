System Requirements

  • Windows 10/11 (64-bit)
  • macOS 11+ (Apple Silicon)
  • OpenGL 3.3+ compatible GPU

First Launch

  • Windows: run `.exe`, approve SmartScreen if prompted.
  • macOS: unzip, move app to Applications, then right-click Open first time.
  • Use audio input and start the visual engine immediately.
