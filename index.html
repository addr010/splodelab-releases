WHAT IT DOES

Clips, shaders, MilkDrop, scripts and live inputs

Play clips, shaders, MilkDrop presets, JavaScript scripts and live inputs. MIDI, OSC, NDI, Syphon and Spout support baked in.

Render FX

Use your collection of MilkDrop presets, then add ISF shaders for transitions and effects.

Scripts

Write scripts for motion graphics, games or deck controls and live chopping on video.

Vōdl scripting

Script every layer at once with text. Expressions, envelopes, shader control and audio-reactive timing.

OSC

Drive it from other tools, controllers, scripts or your own weird rig.

MIDI

Use MIDI for control, scripts and clock sync.

Live sources

NDI, Syphon, Spout, Blackhole or your fishtank over a webcam. Whatever you've got.

Who it's for

Beginners, bedroom setups, home and friends shows, student work, gallery installs, prototypes and weird visual experiments.

Why it exists

Splode Lab started as my own toolbox for video, audio, MIDI and odd creative experiments. Live pulls the fun parts together: clip decks, shaders, scripts, live sources, controller support and audio-reactive visuals.

I like trying new ideas and new tech. If you have a feature you want, make it sound fun and I might have a crack at it.

If you find the app useful and want to support it, there's a Buy Me A Coffee link below. A simple thanks is good too.

System requirements

  • Windows 10/11 (64-bit)
  • macOS 11+ (Apple Silicon)
  • OpenGL 3.3+ compatible GPU

First launch

  • Windows: run the .exe, approve SmartScreen if prompted
  • macOS: unzip, move to Applications, right-click then Open the first time
  • Pick an audio input and the visuals start straight away
