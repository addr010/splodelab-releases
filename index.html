System Requirements

  • Windows 10/11 (64-bit)
  • macOS 11+ (Apple Silicon)
  • OpenGL 3.3+ compatible GPU

First Launch

  • Windows: run the .exe, approve SmartScreen if prompted
  • macOS: unzip, move to Applications, right-click → Open first time
  • Pick an audio input and the visual engine starts immediately
